# **App Name**: TutorHub

## Core Features:

- Student Dashboard: Personalized student dashboards displaying relevant subjects and learning resources.
- Course Resources: Curated list of resources for different classes, and integration of locally stored materials (mockups etc.)
- AI Tutor Assistant: AI-powered tool which recommends appropriate learning resources to the user, depending on their grade level and subjects.
- Subject Forums: Simple text-based forum where users can post questions and provide answers, tagged by subject
- User Accounts: User authentication and authorization.
- notifications: For giving a heads up on the issue or alerts to the user when they are logged in.
- messaging feature: When users are successfully logged in they can get messages or message their tutor directly within the system
- progress tracking: Progress/task tracking system which monitors the performance, task and evaluates areas of improvement for the student user.
- live classes: Live classes through third party services like google classrooms.

## Style Guidelines:

- Primary color: Vibrant blue (#29ABE2) for trust and intelligence.
- Background color: Light gray (#F0F8FF) for a clean, learning-focused environment.
- Accent color: Energetic orange (#FFB347) to highlight interactive elements and important notifications.
- Body font: 'Inter' (sans-serif) for a modern, readable style.
- Headline font: 'Space Grotesk' (sans-serif) for headlines and shorter text requiring emphasis.
- Consistent use of flat, outline-style icons relevant to subjects and features, and clearly labeled interactive UI elements to help usability.
- Clean, grid-based layout to maintain organized and distraction-free content arrangement.
